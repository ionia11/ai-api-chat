# AI API Chat.

Это мой учебный проект на Python.
Я делаю программу для пк на Windows, чтобы общаться с нейросетями (например DeepSeek).


## Зачем этот проект?
Хочу разобраться, как делать программы с кнопками и окошками на PyQt, научиться работать с API.


## Функционал программы
* Работа по API-ключу
* **Чаты:** список чатов, история сообщений.
* **Красивый вид:** простой и понятный интерфейс, ничего лишнего.


## На чем пишу
* **Python** — основной язык.
* **PyQt** — для создания кнопок, полей и самого окна.
* **Библиотека OpenAI(?)** — чтобы отправлять вопросы нейросети и получать ответы.
