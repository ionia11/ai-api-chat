# AI B2B SaaS API Chat

Это мой учебный проект на Python.
Я делаю программу для ПК на Windows, чтобы общаться с нейросетями (например, Gemini).

## Зачем этот проект?

Хочу разобраться, как делать программы с кнопками и окошками на PyQt, научиться работать с API.

## Функционал программы

* Работа по API-ключу.
* **Чаты:** список чатов, история сообщений.
* **Выбор модели:** Gemini 3.5 Flash Lite или Gemini 3.8 Flash.
* Ответы нейросети отображаются с поддержкой Markdown.

## На чём пишу

* **Python** — основной язык.
* **PyQt6** — для создания кнопок, полей и самого окна.
* **Библиотека google-genai** — чтобы отправлять вопросы нейросети и получать ответы.
* **SQLite** — для хранения истории чатов.
