## Введение

тк посчитал это новой идеей. Также это позволияет мне узнать о новых библиотеках.

## 1. Что делает программа

О самой программе: это легковесное решение, которое позволяет общаться с нейросетями по их API.
Общение представляет собой чаты в формате вопрос - ответ. Есть поддержка md текста, поэтому будет сохранятся стиль сообщений. 

## 2. Какие технологии использованы

На чем написан весь проект - `Python (3.15)`
Фреймворк для работы - `PyQT6`
База данных сообщений работает на `SQLite`
Для запросов к ИИ - `google-genai`
А для хранения текущих настроек `python-dotenv`
Отдельно стоит упомянуть модуль `QThread`, который позволяет обрабатывать фоновые процессы отдельным потоком

## 3. Как устроена программа

`main.py` - собирает главное окно и обрабатывает логику приложения
`ui/` - дизайн и его настройки
`api_request.py` - запрос к нейросети в отдельном потоке
`database/db.py` - сохранение чатов и сообщений
`app_settings.py` - настройки

## 4. Как работает запрос

* Пользователь вводит запрос
* База данных получает контекст (или создает новый чат)
* Запускается отдельный поток
* Запрос генерации текста по API
* Получение ответа
* Определение полученных данных: ошибка или нормальный текст
* Сохранение ответа в базу данных
* Отображение ответа пользователю

## 5. Проверка работы

* Неверный API ключ:
  - Ошибка при запросе
* Выход при генерации:
  - Диалог с уточнением
* Пустой запрос:
  - Нельзя отправить пустой запрос

## 6. Как пользоваться

Сборка `.\.venv\Scripts\python.exe -m PyInstaller AIChat.spec --clean --noconfirm | Select-Object -Last 5`
И просто запусть `AIChat.exe`!
_в папке создадутся системные файлы_
