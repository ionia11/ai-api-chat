# Техническое задание: десктопный чат с нейросетью

## 1. Цель проекта

Создать приложение для Windows на Python и PyQt. Оно позволит общаться с нейросетью через API с помощью личного API-ключа. В первой версии используется совместимый с Google AI API.

## 2. Технологии

- Python 3.14 или новее.
- PyQt6 для графического интерфейса.
- Библиотека `google-genai` для запросов к API.
- `QThread` для выполнения запросов в отдельном потоке.
- `QWidget` для UI.
- JSON для истории и контекста. В `.env` будет хранится api ключ.

## 3. Функциональные требования

### 3.1. API-ключ

- Пользователь может ввести API-ключ.
- Ключ можно скрыть в поле ввода.
- Ключ сохраняется для следующих запусков приложения.
- Приложение сообщает, если ключ неверный.

### 3.2. Чат

- В окне показывается история текущего разговора.
- Сообщения пользователя и нейросети легко различить.
- Внизу есть поле для ввода сообщения.
- Сообщение можно отправить кнопкой или клавишами Enter.
- Во время ожидания ответа показывается статус загрузки.

### 3.3. Запросы и ошибки

- Запросы к API выполняются в фоновом потоке.
- Ответ нейросети показывается в окне чата.
- Приложение понятно сообщает об отсутствии интернета, неверном ключе и превышении лимита запросов.

## 4. Интерфейс

- Интерфейс простой и понятный.
- Окно можно развернуть на весь экран.
- Логика виджетов не ломается.
- Список чатов с возможностью создать, выбрать и удалить чат.
- Выбор модели из списка(позже).

## 5. План первой версии

Сначала сделать ввод и сохранение API-ключа, одно окно чата и отправку запросов в фоновом потоке. После этого можно добавить список чатов, потоковый вывод и выбор модели.
